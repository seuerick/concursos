## 2. Provas Objetivas (P1, P2, P3)

| Prova | Área | Itens | Pontos/item | Máximo |
|---|---|---|---|---|
| P1 | Conhecimentos básicos | 40 | +1,00 / −1,00 | 40,00 |
| P2 | Conhecimentos complementares | 40 | +1,00 / −1,00 | 40,00 |
| P3 | Conhecimentos específicos | 90 | +2,00 / −2,00 | 180,00 |
| **Total** | | **170** | | **260,00** |

### 2.1 Regras de pontuação
- Cada item vale **+1,00** (P1/P2) ou **+2,00** (P3) se marcado corretamente.
- Cada item vale **−1,00** (P1/P2) ou **−2,00** (P3) se marcado incorretamente.
- Item em **branco** (não marcado): **0,00** ponto.
- Não há nota mínima por item; a nota de cada prova é a soma algébrica dos itens.

### 2.2 Nota final nas objetivas
```
NFPO = NP1 + NP2 + NP3        (máximo 260,00 pontos)
```

### 2.3 Critérios de eliminação (objetivas)
Será eliminado o candidato que obtiver:

| Condição | Valor mínimo |
|---|---|
| NP1 (básicos) | < 8,00 |
| NP2 (complementares) | < 12,00 |
| NP3 (específicos) | < 54,00 |
| NFPO (total) | < 78,00 |

> **Estratégia**: como P3 vale o dobro por item, o desempenho em conhecimentos específicos é decisivo.
> Com 90 itens, é preciso acertar ~27 itens líquidos (54/2) para não ser eliminado.

## 3. Prova Discursiva (P4)

- **2 questões**, total de **100,00 pontos**.
- Texto manuscrito, caneta esferográfica de tinta preta e material transparente.
- Fuga ao tema ou nota negativa → **zero** na questão.

| Questão | Área | Limite de linhas | Pontos |
|---|---|---|---|
| Q1 | Conhecimentos complementares | 30 linhas | 30,00 |
| Q2 | Situação-problema (específicos do cargo) | 60 linhas | 70,00 |

### 3.1 Fórmulas de pontuação
```
NQ1 = NC − 6 × NE ÷ TL
NQ2 = NC − 14 × NE ÷ TL
```
Onde:
- **NC** = número de acertos (linhas que atendem ao solicitado);
- **NE** = número de erros (linhas que não atendem ao solicitado);
- **TL** = total de linhas efetivamente escritas.

> A penalidade por erro é proporcional ao total de linhas escritas: quanto mais linhas, menor o impacto
> de cada erro — mas erros sempre reduzem a nota.

### 3.2 Aprovação na discursiva
```
NFPD = NQ1 + NQ2 ≥ 50,00 pontos
```

## 4. Nota Final no Concurso

```
NFC = NFPO/26 + NFPD/10
```

- **NFPO/26**: nota das objetivas normalizada para escala de 0 a 10 (260/26).
- **NFPD/10**: nota da discursiva normalizada para escala de 0 a 10 (100/10).
- A classificação final considera a NFC, com desempate conforme edital (maior NFPD, maior NFPO, maior NP3, etc.).

## 6. Dicas de Prova (Método Cebraspe)

1. **Não chute em branco**: item errado tira ponto. Só marque quando tiver confiança.
2. **P3 vale o dobro**: priorize o domínio dos conhecimentos específicos do cargo.
3. **Gestão de tempo**: 170 itens em 5h ≈ 1,7 min/item. Reserve tempo para revisão.
4. **Discursiva**: escreva dentro do limite de linhas; linhas fora do tema contam como erro.
5. **Leia o enunciado com atenção**: o Cebraspe usa pegadinhas de "exceto", "não", "somente".
